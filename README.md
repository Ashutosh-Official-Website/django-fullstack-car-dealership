# django-fullstack-car-dealership

## Project Name
**Cars Dealership: National Car Retailer Web Application**

### Project Description
This project is a comprehensive full-stack web application designed for a national car retailer. It allows users to view dealership locations across the U.S., read reviews from other customers, and post their own car purchase experiences.

### Key Features
* **User Authentication:** Sign-up, Login, and Logout functionality.
* **Dealer Management:** Browse dealerships by state.
* **Review System:** Integrated sentiment analysis for customer reviews.
* **Microservices:** Backend powered by Node.js, Go, and Django.
* **Cloud Native:** Deployed using Docker and Kubernetes on IBM Cloud.

### Tech Stack
* **Frontend:** React, HTML5, CSS3, Bootstrap.
* **Backend:** Django, Flask, Node.js.
* **Database:** MongoDB, SQLite.
* **CI/CD:** GitHub Actions.
